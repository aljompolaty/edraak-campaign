# حملة إدراك الهندسية – التكييف على فيسبوك

صفحة الملفات الخاصة بالحملة (15 يوماً).

## الملفات
- `index.html`: الصفحة الرئيسية وروابط الملفات.
- `plan.html`: خطة الحملة التفاعلية (المنشورات والتقويم والبرومبتات والمؤشرات).
- `content.html`: نصوص الحملة باللهجة السودانية مع النسخة الفصحى.
- `downloads/plan-calendar.xlsx`: ملف خطة الحملة.
- `downloads/content-editing.xlsx`: ملف المحتوى.

## الرفع على GitHub Pages
1. أنشئ مستودعاً عاماً (Public) باسم مثل `edraak-campaign`.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع (Add file ← Upload files).
3. من Settings ← Pages اختر Deploy from a branch ← main ← /(root) ← Save.
4. الرابط: `https://<اسم-الحساب>.github.io/edraak-campaign/`

ملاحظة: المستودع العام مفتوح لمن يملك الرابط.
